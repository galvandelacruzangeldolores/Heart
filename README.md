# Análisis de enfermedades cardíacas

## Descripción

Proyecto de análisis exploratorio y preprocesamiento de un conjunto de datos sobre enfermedades cardíacas.

## Dataset

El archivo utilizado es `heart_disease.csv`.

La variable `num` representa el diagnóstico:

- `0`: sin enfermedad cardíaca
- `1`: con enfermedad cardíaca

## Tecnologías utilizadas

- Python
- JupyterLab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Instalación

Crear un entorno virtual e instalar las dependencias:

```bash
python3 -m venv rosa
source rosa/bin/activate
pip install -r requirements.txt
```

## Ejecución

Abrir JupyterLab:

```bash
jupyter lab
```

Después abrir el notebook `analisis_heart.ipynb`.
